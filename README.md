# Catalyst Product Cost Calculator

Customer product-quantity and cost calculator for Catalyst Concrete Solutions.

Open index.html in a browser, serve this folder with any static server, or publish the main branch root through GitHub Pages.

Includes editable dosage and recipes, cover blocks, customer prices, 1:8 and custom 1:1 preparation, AMOLED and light themes, and printable estimates.

Prices exclude GST and freight. Liquid volume costing uses the entered density. Saved settings stay in the browser.
